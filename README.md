# 💱 Currency Converter in C

A simple **Currency Converter program written in C** that allows users to convert between **US Dollars (USD), Indian Rupees (INR), and Japanese Yen (JPY)**.

The program uses a menu-driven approach with `switch-case` and allows the user to perform multiple conversions without restarting the program.

## ✨ Features

- 💵 Dollar → Rupees
- 🇮🇳 Rupees → Dollar
- 💴 Yen → Rupees
- 🇮🇳 Rupees → Yen
- 🔄 Perform multiple conversions in one run
- ❌ Handles invalid menu choices
- 🖥️ Simple command-line interface
- 📚 Beginner-friendly C program

## 📋 Available Operations

When the program starts, the user can select one of the following options:

| Option | Conversion |
|--------|------------|
| 1 | Dollar → Rupees |
| 2 | Yen → Rupees |
| 3 | Rupees → Dollar |
| 4 | Rupees → Yen |

After completing a conversion, the program asks whether the user wants to perform another operation.
